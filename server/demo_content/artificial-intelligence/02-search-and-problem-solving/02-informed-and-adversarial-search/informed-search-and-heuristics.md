# Informed Search and Heuristics

## 1. Best-First Search and Heuristic Functions

Informed (heuristic) search uses problem-specific knowledge beyond the problem definition. The general scheme is **best-first search**: expand the frontier node with the lowest value of an **evaluation function** `f(n)`, using a priority queue.

A **heuristic function** `h(n)` estimates the cost of the cheapest path from the state at node `n` to a goal. Requirements: `h(n) >= 0` and `h(goal) = 0`. In the Romania route-finding problem a natural heuristic is the **straight-line distance** to Bucharest, `h_SLD`; for example `h_SLD(Arad) = 366` km.

## 2. Greedy Best-First Search

Greedy best-first search uses `f(n) = h(n)`: it always expands the node that appears closest to the goal.

- From Arad it goes Arad → Sibiu → Fagaras → Bucharest, path cost 140 + 99 + 211 = **450 km**. The optimal route, Arad → Sibiu → Rimnicu Vilcea → Pitesti → Bucharest, costs 140 + 80 + 97 + 101 = **418 km**. Greedy search is therefore **not optimal**.
- Tree-like greedy search is **incomplete**: it can oscillate (e.g. from Iasi toward Fagaras, it repeatedly returns to Neamt). The graph-search version is complete in finite state spaces.
- Worst-case time and space `O(b^m)`; with a good heuristic the cost can be reduced dramatically.

## 3. A* Search

A* uses

```
f(n) = g(n) + h(n)
```

where `g(n)` is the path cost from the start to `n` and `h(n)` the estimated cost from `n` to the goal. Thus `f(n)` estimates the cost of the cheapest solution through `n`. A* is identical to uniform-cost search except that it orders by `g + h` instead of `g`; UCS is A* with `h = 0`.

```python
import heapq

def a_star(problem, h):
    start = Node(problem.initial)
    frontier = [(h(start.state), start)]
    best_g = {problem.initial: 0}
    while frontier:
        f, node = heapq.heappop(frontier)
        if problem.is_goal(node.state):     # test on expansion
            return node
        for child in expand(problem, node):
            if child.g < best_g.get(child.state, float("inf")):
                best_g[child.state] = child.g
                heapq.heappush(frontier, (child.g + h(child.state), child))
    return None
```

### 3.1 Admissible heuristics

`h` is **admissible** if it never overestimates the true cost to reach the goal: `h(n) <= h*(n)` for every node, where `h*(n)` is the true optimal cost from `n`. Straight-line distance is admissible because a straight line is the shortest path between two points.

### 3.2 Consistent (monotone) heuristics

`h` is **consistent** if for every node `n` and every successor `n'` generated by action `a`:

```
h(n) <= c(n, a, n') + h(n')
```

This is a form of the **triangle inequality**. Properties:

- Every consistent heuristic is admissible (proof by induction on the number of steps to the goal). The converse does not hold, although most natural admissible heuristics are also consistent.
- If `h` is consistent, `f` values are **non-decreasing** along any path: `f(n') = g(n) + c(n,a,n') + h(n') >= g(n) + h(n) = f(n)`.
- Consequently, the first time A* (graph search) selects a state for expansion, it has found an optimal path to that state.

### 3.3 Optimality of A*: proof sketch

**Claim.** Tree-search A* with an admissible heuristic returns an optimal solution.

Let `C*` be the optimal solution cost. Suppose a suboptimal goal node `G2` is on the frontier, so `g(G2) > C*`. Because `h(G2) = 0`, `f(G2) = g(G2) > C*`.

Since a solution exists, some node `n` on an optimal path is also on the frontier (by induction, the frontier always contains such a node until the optimal goal is expanded). By admissibility:

```
f(n) = g(n) + h(n) <= g(n) + h*(n) = C*
```

Therefore `f(n) <= C* < f(G2)`, so A* expands `n` before `G2`. Repeating the argument, A* expands all nodes on the optimal path before `G2` and returns the optimal goal first. For **graph search** (which discards repeated states), the guarantee requires a **consistent** heuristic, or else re-opening of closed nodes.

### 3.4 Further properties

- A* expands all nodes with `f(n) < C*`, some with `f(n) = C*`, and none with `f(n) > C*`. Nodes with `f(n) > C*` are **pruned** without examination.
- A* is **optimally efficient** among optimal algorithms that extend search paths from the root using the same consistent heuristic: no such algorithm is guaranteed to expand fewer nodes (up to tie-breaking).
- The main drawback is **space**: A* keeps all generated nodes in memory, so it typically runs out of memory before time. Memory-bounded variants include **IDA*** (iterative deepening on f-cost) and **SMA*** (simplified memory-bounded A*).
- **Weighted A*** uses `f = g + W*h` with `W > 1`; it expands fewer nodes and returns a solution within factor `W` of optimal.

## 4. Heuristics for the 8-Puzzle

The 8-puzzle has 9!/2 = **181,440** reachable states. Average solution cost for a random instance is about **22 steps** and the branching factor is about **3** (2 in a corner, 3 on an edge, 4 in the centre).

Two admissible heuristics:

- `h1` = **number of misplaced tiles** (blank not counted). Admissible because every misplaced tile must move at least once.
- `h2` = **sum of Manhattan distances** of each tile from its goal position. Admissible because each move shifts one tile by one square.

**Example.** Start state (rows top to bottom, `_` is blank): `7 2 4 / 5 _ 6 / 8 3 1`. Goal: `_ 1 2 / 3 4 5 / 6 7 8`.

| Tile | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | Total |
|---|---|---|---|---|---|---|---|---|---|
| Misplaced? | yes | yes | yes | yes | yes | yes | yes | yes | h1 = 8 |
| Manhattan distance | 3 | 1 | 2 | 2 | 2 | 3 | 3 | 2 | h2 = 18 |

The true optimal solution cost is 26, so both heuristics underestimate, as required.

### 4.1 Dominance

`h2` **dominates** `h1` because `h2(n) >= h1(n)` for every `n`. A* with `h2` never expands more nodes than A* with `h1` (apart from tie-breaking), since every node with `f(n) < C*`, i.e. `h(n) < C* - g(n)`, is surely expanded. A larger admissible heuristic is always better, as long as it is cheap to compute. Given admissible heuristics `h_a, ..., h_k`, `h(n) = max(h_a(n), ..., h_k(n))` is admissible and dominates each component.

### 4.2 Deriving heuristics from relaxed problems

A **relaxed problem** has fewer restrictions on actions. The cost of an optimal solution to a relaxed problem is an admissible (and consistent) heuristic for the original. For the 8-puzzle rule "a tile can move from A to B if A is adjacent to B and B is blank":

- Removing both conditions (a tile can move anywhere) gives `h1`.
- Removing "B is blank" gives `h2`.

**Pattern databases** store exact solution costs for subproblems (e.g. tiles 1–4) and are much stronger than Manhattan distance.

## 5. Effective Branching Factor

If A* generates `N` nodes for a solution at depth `d`, the **effective branching factor** `b*` is the branching factor a uniform tree of depth `d` would need to contain `N + 1` nodes:

```
N + 1 = 1 + b* + (b*)^2 + ... + (b*)^d
```

Example: a solution at depth 5 found by generating 52 nodes gives `b* ≈ 1.92`. A well-designed heuristic has `b*` close to 1.

In the classic experiment by Russell and Norvig, averaged over 100 random 8-puzzle instances with solution depth 12:

| Algorithm | Nodes generated | Effective branching factor |
|---|---|---|
| Iterative deepening | 3,644,035 | 2.78 |
| A* with h1 | 227 | 1.42 |
| A* with h2 | 73 | 1.24 |

## 6. Exam Pitfalls

- Greedy best-first uses `h` only; A* uses `g + h`.
- Admissible means **never overestimates**; an admissible heuristic may (and usually does) underestimate.
- Consistency implies admissibility, not the reverse.
- Test for the goal when a node is **expanded**, not when generated, or optimality is lost.
