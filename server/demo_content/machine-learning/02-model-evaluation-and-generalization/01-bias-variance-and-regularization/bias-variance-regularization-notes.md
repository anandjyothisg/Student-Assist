# Bias–Variance Trade-off and Regularization

## 1. Generalisation

The goal of learning is low error on **unseen** data drawn from the same distribution, not on the training set. The **generalisation gap** is the difference between test error and training error.

- **Underfitting**: the model is too simple to capture the underlying pattern. Training error is high, and validation error is similarly high. Example: fitting a straight line to data generated by a quadratic.
- **Overfitting**: the model is flexible enough to fit noise in the training data. Training error is very low but validation error is much higher. Example: a degree-15 polynomial through 20 noisy points, which passes through every point but oscillates wildly between them.

## 2. The Bias–Variance Decomposition

Assume `y = f(x) + ε` with `E[ε] = 0` and `Var(ε) = σ²`. Let `f̂` be the model learned from a random training set `D`. For a fixed input `x`, the expected squared error over training sets and noise decomposes as:

```
E[(y - f̂(x))^2] = Bias[f̂(x)]^2 + Var[f̂(x)] + σ²

Bias[f̂(x)] = E_D[f̂(x)] - f(x)
Var[f̂(x)]  = E_D[(f̂(x) - E_D[f̂(x)])^2]
```

- **Bias**: error from wrong assumptions; how far the *average* model (over many training sets) is from the truth. High bias causes underfitting.
- **Variance**: how much the learned model changes when trained on different samples. High variance causes overfitting.
- **Irreducible error** `σ²`: noise inherent in the data; no model can remove it.

As model complexity increases, bias typically decreases and variance increases. Total error is U-shaped in complexity, and the best model sits at the bottom of the U.

| Model / setting | Bias | Variance |
|---|---|---|
| Linear regression on non-linear data | High | Low |
| High-degree polynomial | Low | High |
| k-NN with k = 1 | Low | High |
| k-NN with large k | High | Low |
| Deep unpruned decision tree | Low | High |
| Strong regularisation (large λ) | High | Low |

## 3. Diagnosing with Learning Curves

A **learning curve** plots training and validation error against training-set size.

- **High bias**: both curves plateau close together at a high error. Adding more data **does not help**; increase model capacity instead.
- **High variance**: a large gap between low training error and higher validation error; the gap narrows as data increases. More data **does help**.

| Symptom | Likely cause | Remedies |
|---|---|---|
| High train error, val ≈ train | High bias | More features, polynomial features, bigger model, decrease λ, train longer |
| Low train error, val much higher | High variance | More data, fewer features, increase λ, dropout, early stopping, simpler model, ensembling |

## 4. Regularisation

Regularisation adds a penalty on model complexity to the training objective, deliberately accepting a little bias in exchange for a larger reduction in variance.

### 4.1 L2 regularisation (ridge regression)

```
J(θ) = (1/2m) [ Σ_i (h_θ(x^(i)) - y^(i))^2 + λ Σ_{j=1..n} θ_j^2 ]
```

- The intercept `θ0` is **not** penalised.
- Closed form: `θ = (XᵀX + λL)^(-1) Xᵀ y`, where `L` is the identity matrix with its top-left entry set to 0. For `λ > 0`, the matrix is always invertible, which also cures the singularity caused by collinear features or `m <= n`.
- Gradient descent update becomes **weight decay**:

```
θ_j := θ_j (1 - α λ / m) - α (1/m) Σ_i (h_θ(x^(i)) - y^(i)) x_j^(i)
```

Each step first shrinks `θ_j` by a factor slightly less than 1.

- Ridge shrinks all coefficients smoothly towards zero but rarely makes any exactly zero.

### 4.2 L1 regularisation (lasso)

```
J(θ) = (1/2m) Σ_i (h_θ(x^(i)) - y^(i))^2 + (λ/m) Σ_{j=1..n} |θ_j|
```

- Produces **sparse** solutions: many coefficients become exactly zero, performing automatic **feature selection**.
- No closed-form solution because `|θ_j|` is not differentiable at 0; solved by coordinate descent with the **soft-thresholding** operator `S(z, γ) = sign(z) · max(|z| - γ, 0)`, or by subgradient and proximal methods.
- With highly correlated features, lasso tends to pick one arbitrarily.

**Geometric intuition**: minimising the loss subject to `Σ|θ_j| <= t` (a diamond in 2-D) versus `Σθ_j^2 <= t` (a circle). The elliptical loss contours typically first touch the diamond at a **corner**, where some coordinates are zero; they touch the circle at a generic point.

### 4.3 Comparison

| | L2 (ridge) | L1 (lasso) |
|---|---|---|
| Penalty | λ Σ θ_j² | λ Σ \|θ_j\| |
| Sparsity | No (small but non-zero weights) | Yes (exact zeros) |
| Closed form | Yes | No |
| Correlated features | Shares weight among them | Picks one |
| Bayesian interpretation | Gaussian prior on θ (MAP) | Laplace prior on θ (MAP) |
| Constraint region | Circle / sphere | Diamond / cross-polytope |

**Elastic net** combines both: `λ1 Σ|θ_j| + λ2 Σθ_j²`, giving sparsity while handling groups of correlated features.

### 4.4 The effect of λ

- `λ = 0`: ordinary least squares; no regularisation, risk of overfitting.
- Small λ: slight shrinkage; variance decreases.
- Large λ: coefficients pushed towards 0; the model approaches the constant `θ0` (the mean of `y`); **underfitting**.
- Training error increases monotonically with λ; validation error is typically U-shaped.

Choose λ by cross-validation over a **logarithmic grid**, e.g. `10^-4, 10^-3, ..., 10^2`. Because the penalty treats all coefficients equally, **standardise features** first; otherwise features measured on large scales are penalised less.

## 5. Regularisation in Neural Networks

### 5.1 Early stopping

Monitor validation loss during training and stop when it has not improved for a set number of epochs (**patience**, e.g. 10), restoring the weights from the best epoch. Training loss keeps falling, but validation loss eventually starts to rise as the network begins to overfit. For a quadratic loss with gradient descent, early stopping behaves approximately like L2 regularisation, with the number of steps playing the role of `1/λ`.

### 5.2 Dropout

Dropout (Srivastava et al., 2014) randomly sets each hidden unit's activation to zero with probability `p` during training (commonly `p = 0.5` for hidden layers, around 0.2 for inputs). In **inverted dropout**, the surviving activations are scaled by `1/(1 - p)` during training so that no rescaling is needed at test time, when all units are used. Dropout prevents units from co-adapting and can be viewed as training an exponentially large ensemble of thinned networks that share weights.

### 5.3 Other techniques

- **Data augmentation**: enlarge the training set with label-preserving transformations (flips, crops, rotations).
- **Weight decay** in optimisers: L2 penalty applied directly in the update.
- **Reducing capacity**: fewer layers or units, or fewer features.

## 6. Exam Pitfalls

- Regularisation reduces **variance**, not bias; too much of it increases bias.
- Do not penalise the bias/intercept term.
- More data cures variance problems, not bias problems.
- Disable dropout at inference time.
